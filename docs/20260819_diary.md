Dum vita est, spes est.
    Dum = 只要/当……时候。

    vita = 生命（主格）。

    est = 是（第三人称单数）。

    spes = 希望（主格）。

    est = 是。

    直译：“当生命存在时，希望存在。”

    惯用翻译：“有生命，就有希望。” / “活着就有希望。” / “留得青山在，不怕没柴烧。”
	
 “Dum spiro, spero”（我呼吸，故我希望）
